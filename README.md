# Mobile Application Development Laboratory

IFET College of Engineering - Department of Computer Science & Engineering

This repository-ready package contains the program code listed in the Mobile Application Development Laboratory manual (23CS7L01), Experiments 1-10.

## Experiments
1. Visiting Card using Layout Components
2. Basic Calculator using Buttons, TextView and EditText
3. Sign-Up Activity with Validation
4. Random Wallpaper Changer
5. X, Y Sensor Values using Sensor Service
6. Start-Stop Counter using Buttons
7. XML and JSON Parsing in Android
8. Phone Dialer with CALL and SAVE functionalities
9. Text-to-Speech using the TextToSpeech API
10. Current Location using Google Maps Service

## Important
The files in this package are organized for GitHub upload from the code listings in the supplied lab manual. The manual contains some inconsistencies between its algorithms/results and sample code; those sample-code inconsistencies have intentionally not been silently corrected here.

This is a code-only package, not a set of complete Android Studio projects.
